Privacy Policy

Last updated: 2026-10-30

In short: the White Shadow launcher has no accounts with us, no analytics and no telemetry. Your settings, usernames, skins and worlds stay on your computer. This website uses no cookies and no trackers.

The launcher

Everything the launcher stores is kept in its data folder on your computer (settings, the usernames you add, saved skins, instances, worlds, mods and a log file). We never receive it. Deleting that folder removes it all. You can move the folder in Settings → Storage.

The launcher connects to the internet only to do the things you ask it to do:

ServiceWhy
Mojang (piston-meta, launcher libraries, resources)Download Minecraft game files and version lists.
Fabric (meta.fabricmc.net, maven.fabricmc.net)Download the Fabric mod loader.
Modrinth and CurseForgeSearch for and download mods, resource packs and shaders when you use the content browser. CurseForge is used only if you enter your own API key.
AdoptiumDownload Java automatically when the right version is not installed.
Microsoft (WebView2 installer)One-time setup of the Windows component that displays the app window, only if it is missing.
MinotarShow the head of your username. This sends the username to Minotar.
GitHubCheck whether a newer version of the launcher exists (only in builds published through GitHub).
Servers you addShow their status and let you join. The launcher connects to the addresses you enter.

Those services receive your IP address and the request itself, as with any internet connection, and have their own privacy policies. The launcher sends them nothing else.

This website

The site sets no cookies and has no analytics. Depending on how it is hosted, it either serves the download file itself or reads the latest release information from GitHub, which can then see your IP address. Our web host may keep ordinary server logs.
