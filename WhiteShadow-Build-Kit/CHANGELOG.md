# Changelog

## 1.0.0
- Native app window, installs like any other launcher (Windows setup file, macOS app, Linux binary). No Python needed.
- Home, Play (instance library), Mods, Resource Packs, Servers, Skins, Settings.
- Content browser for mods, resource packs and shaders (Modrinth; CurseForge with your own free API key) with version and dependency details. Required dependencies are installed automatically.
- Saved skins library; the active skin is applied on every launch.
- Instances with per-instance version, loader, memory and Java; share / import profiles (.wsprof).
- Servers with live status and one-click join.
- Crash helper with one-click fixes, automatic Java download, 12 interface languages, no telemetry.
